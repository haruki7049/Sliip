# Examples

The `examples/` directory contains various sample programs demonstrating different features of lll:

- **hello-lll.lll** - Basic hello world program
- **arithmetic.lll** - Working with numbers and numeric types
- **variables.lll** - Variable definitions and references
- **functions.lll** - Lambda functions and function composition
- **higher-order.lll** - Higher-order functions (functions returning functions)
- **chaining.lll** - Function chaining and composition
- **recursive-refs.lll** - Recursive variable references
- **multi-param.lll** - Functions with multiple parameters
- **closure.lll** - Closures and captured environments
- **nested-calls.lll** - Deeply nested function calls
- **type-annotations.lll** - Type system and explicit type annotations

Run any example with:

```bash
cargo run -- examples/<filename>.lll
```
